## 🔍 How I Approach QA

My development and design background gives me a broader perspective when testing products.

- 🐛 Identify, reproduce, and document bugs
- 🧪 Perform functional and regression testing
- 🔎 Test edge cases and different user flows
- 🎨 Review UI against design specifications
- 📱 Check responsive behavior across screen sizes
- 🔗 Validate front-end and backend interactions
- 🧠 Think from the user's perspective when identifying issues
- 🔧 Debug issues with an understanding of the underlying code
- ♿ Consider accessibility and usability during testing

I don't just ask **"Does it work?"**

I also ask:

> **"What happens if the user does something unexpected?"**
